# Abdulrahman Ali Hussein | Portfolio

A modern, fast, and feature-rich React SPA portfolio with a PHP backend. Features PWA capabilities, i18n support, Cmd+K global search, and rate-limited email logic.

## 🚀 Setup Instructions

### 1. Frontend Setup (React)
Ensure you have Node.js installed.
```bash
# Install dependencies (Fuse.js for search is required)
npm install
npm install fuse.js

# Start development server
npm run dev
